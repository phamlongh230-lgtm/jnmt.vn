## Description

Thiết kế wireframe và design spec cho 4 trang chính: Trang chủ, Tài liệu học tập, Lịch thi, Thông báo trường. Bao gồm mobile layout (375px) và desktop. Phải document vào `docs/technical/DESIGN_SYSTEM.md`.

## Acceptance Criteria

- [ ] Wireframe Trang chủ — hero, navigation, quick links tới 4 sections
- [ ] Wireframe Trang tài liệu — danh sách có filter theo môn, search bar, card tài liệu
- [ ] Wireframe Trang lịch thi — calendar view hoặc list view, filter theo tháng/môn
- [ ] Wireframe Thông báo — list thông báo mới nhất, detail view
- [ ] Mobile layout (375px) cho tất cả 4 trang
- [ ] Color palette và typography cơ bản documented trong DESIGN_SYSTEM.md
- [ ] Navigation pattern (bottom nav mobile / top nav desktop) quyết định và documented
- [ ] Component inventory cơ bản: Button, Card, Input, Badge documented
