## Description

Viết copy cho Homepage, trang /tai-lieu, và trang /lich-thi — bao gồm H1, sub-headline, CTA text, title tag, và meta description cho mỗi trang. Copy phải theo brand voice trong CONTENT_STRATEGY.md (thân thiện, gần gũi với học sinh) và tối ưu cho SEO keywords đã xác định.

## Acceptance Criteria

- [ ] Homepage: H1, sub-headline, primary CTA, secondary CTA, title tag, meta description
- [ ] /tai-lieu: H1, intro text, title tag, meta description
- [ ] /lich-thi: H1, intro text, title tag, meta description
- [ ] Copy dùng "bạn" (không phải "học sinh" hay "người dùng")
- [ ] Keywords target xuất hiện tự nhiên trong headings và meta descriptions
- [ ] Copy được document vào CONTENT_STRATEGY.md Page Copy Library section

## Technical Notes

- Primary keywords: "tra cứu điểm thi THPT", "lịch thi THPT 2026", "tài liệu học tập THPT"
- Xem CONTENT_STRATEGY.md để biết full voice guidelines và forbidden phrases
